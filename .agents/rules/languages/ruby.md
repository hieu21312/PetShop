# Ruby Standards

- Prefer `snake_case` for methods and variables and `PascalCase` for classes and modules.
- Use 2 spaces for indentation.
- Use predicate method names ending in `?` for boolean-returning methods.
- Use mutating method names ending in `!` only when they meaningfully signal a dangerous or state-changing variant.
- Prefer readable, explicit control flow over dense metaprogramming in business-critical paths.
